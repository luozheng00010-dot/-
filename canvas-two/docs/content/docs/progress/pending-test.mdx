- 自动剪辑模型联动：AI 文案、AI 关键词及仅填主题提交任务均使用管理设置的模型；后者先补齐文本再提交引擎，模型失败时不创建剪辑任务。手填文案＋本地素材使用语义匹配文字与向量模型，手填文案＋非本地素材仅在缺少关键词时调用模型。任务参数及列表不得包含渠道 API Key；切换配置不改变已提交任务的文本。
- 自动剪辑模型部署：新增 `auto_video_settings` 表；开发需完整重启以生成 Prisma Client 并同步数据库，迁移部署执行新增迁移后生成客户端并重启主服务。主站文案与关键词不再读取引擎 config.toml 的 LLM 配置；引擎原版 WebUI/CLI 不受此设置控制。已补权限、失效配置、文本补全和密钥隔离回归用例，未执行构建、测试或迁移。

- 中文视频文件名：上传 `视频.mp4`、`货号ABC-001 产品展示（正面）.MP4`、`新品🎬.mov` 及英文文件名，确认有效视频正常入库、列表和预览标题保留原名，不出现乱码或非法文件名错误。已补 multipart 接口回归用例，覆盖引擎转发、数据库写入和接口返回名称；本次未执行测试或构建。

- 素材库模块归属：自动剪辑菜单应包含「剪辑工作台」和「本地素材库」，素材库地址为 `/auto-video/materials`，首页不再出现独立素材库卡片。桌面和移动端进入素材库时只高亮对应子菜单；剪辑页管理链接和素材库返回链接应正常。入口不再引用不存在的 FolderVideo 图标。
- 桌面开发启动修复：完整退出旧客户端再启动，即使存在旧 `server/dist`，后端和 worker 也应使用源码；先生成 Prisma Client、同步开发数据库，再启动接口。登录后货号、分类和素材列表不应返回 API not found。外部旧后端占用 3001 时需先停止；数据库同步失败时检查启动日志。本次未执行构建或数据库同步，需重启验收。

- 本地视频素材库：入口位于「自动剪辑 → 本地素材库」，全体登录成员可维护共享货号、分类、视频。仅允许视频，单文件上限 200 MB；货号、分类忽略首尾空格和英文字母大小写判重。需验证并发重复创建被唯一约束拦截，存在素材时不能删除货号或分类。
- 素材上传与管理：先选择货号和分类再批量上传，逐文件显示成功／失败，重试不重复上传成功项；验证图片、伪装成视频的图片、空文件、超限文件和缺少归类均被拦截。验证货号搜索、分类筛选、分页、原文件名、大小、上传时间、修改归类及视频 Range 预览；浏览器不支持的编码可能无法直接预览。
- 自动剪辑素材选择：选择本地素材库后，单货号＋多分类组成候选池；切换货号清空分类，可一键选择全部有素材分类，候选列表支持翻页。无候选或加载失败时不能生成；服务端只使用重新查询到的有效视频，拒绝直接传入本地文件路径。验证不同货号视频不会混入；本地不显示顺序／随机拼接和默认慢放入口，多条方案分别预览确认。
- 素材生命周期：提交后新增、改名、调整归类或删除视频不改变任务固定文件清单；删除退出候选池但不释放磁盘。验证重启后元数据和视频保留、普通成员间共享、未登录访问拒绝；原有未归类文件不自动入库、不删除。
- 素材库部署与故障：启动开发服务时沿用 Prisma generate/db push；迁移部署使用新增 local_video_library 迁移并重新生成 Prisma Client。验证引擎不可用提示、引擎内容校验失败不入库、入库失败补偿删除文件；补偿失败需在服务端日志记录文件键。已补 Node 接口和 Python 上传／Range 用例，本次未执行测试或构建。

- 详情页比例选项文案：比例下拉应显示“方形 1:1”“横向 3:2”“竖向 2:3”等方向标签，21:9 显示为“横向 21:9”。

- 详情页提示词生成配置：提示词弹窗下方可选择模型、1k/2k/4k 分辨率、原参考图比例或固定比例及 auto/low/medium/high 质量；选择比例后显示实际像素，点击生成会保存提示词与配对配置并生成当前配对，刷新后配置仍保留。

- 详情页提示词参考素材条：提示词弹窗顶部默认显示商品四视角主图和原参考图；生成成功后追加当前生成图；支持通过加号上传或恢复素材、缩略图叉号移除，素材集合与 @ 图片 chip 同步，远程和本地生成按素材条顺序发送图片。

- 1:1 主图复刻：只能选择已有四视角主图的商品，上传 1–6 张参考主图后逐张生成固定 1:1 结果；商品名称、品牌、产品类别、材质和全部卖点应进入最终提示词，参考图品牌、原文案、价格、水印和独特包装不得直接复制。
- 1:1 主图复刻新建弹窗：点击“新建主图复刻”后商品和模板列表应正常加载，不应出现 `Te.filter is not a function`；仅显示已有四视角主图的商品。
- 1:1 主图复刻重试与局部编辑：首次结果进入生成图，重试和局部编辑进入修改图；候选可通过覆盖成为正式图，旧正式图进入历史，刷新后管理员任务继续更新，个人渠道结果可回写。
- 1:1 主图模板：模板名称和 1–6 张参考主图可创建、编辑、删除和预览，新建主图复刻时模板下拉显示缩略图并载入参考图快照。
- 画布 1:1 主图复刻入口：商品节点可直接预选商品，已有项目直接打开，普通图片节点进入商品选择；画布刷新后应保留关联 metadata。

- 画布图片上传初始尺寸：文件选择上传、拖拽上传和替换已有图片节点后，图片节点均按长边 640px 等比显示；高分辨率图片不会过大，低分辨率图片也不会过小，原图元数据和后续手动缩放结果保持不变。

- 详情页模板库：模板管理页应支持新建、编辑名称、拖动或按钮调整顺序、预览和删除；模板名称在同一成员下重复时应明确拦截，模板参考图支持 1–18 张，非图片、超过 20MB、宽高比超过 3:1 或第 19 张时显示中文提示。

- 详情页模板选择：新建复刻项目的模板下拉项应显示第一张缩略图、模板名称和参考图数量；选择模板会在已有参考图时先确认替换，之后仍可删除、排序和追加。商品切换后只显示同成员模板；模板保存成功后点击“添加新的模板”应自动载入新模板。项目创建后只保存参考图快照，模板后续编辑或删除不影响已有项目和媒体文件。

- 详情页局部编辑弹窗：点击 AI 修改后弹窗应立即关闭，管理员异步任务或个人渠道请求继续生成；生成前也可通过右上角、取消按钮和遮罩关闭弹窗，不应因生成状态失效。

- 详情页候选版本初始化：重启开发服务后详情页列表接口应正常返回，修改图候选表可读写；页面不应再提示“详情页复刻模块服务未完成初始化”。
- 详情页按生成图重试：生成图存在时应显示“按生成图重试”，管理员和个人渠道均使用商品四视角主图加当前正式生成图作为输入，结果进入修改图候选；正式生成图保持不变，候选可继续覆盖或删除。
- 详情页复刻提示词：最终请求不应包含商品名称字段或 `{{product.name}}` 占位符；参考图只出现人物部分肢体时，生成结果应保留可见肢体、姿态和构图，不补全未出现的身体部分。
- 详情页复刻初始提示词：新建配对或恢复默认提示词时应包含品牌、材质和可用卖点变量，不包含商品名称、产品类别或 CTA 要求；参考图有人物时保留姿态、动作、服装展示关系和画面构图，仅替换为明确不同的新面孔。

- 商品图卖点上限：创建和编辑商品最多可保存 50 个卖点，每个卖点仍不超过 80 个字符；超过数量时前后端均应拦截，已有商品资料和生成提示词不受影响。

- 详情页页面启动：开发服务启动后详情页复刻页面应能正常加载，不应因 TSX 语法错误导致 Vite 依赖扫描失败或页面空白。

- 详情页复刻三列结果与局部编辑：参考图、正式生成图和修改图按配对一行展示，图片按原始比例完整显示；重试和局部编辑不覆盖正式图，成功候选可通过历史下拉选择并覆盖，旧正式图进入历史。管理员候选任务应由 Worker 更新候选版本，个人渠道刷新后未完成修改显示中断；局部编辑始终使用当前正式图和画布同款蒙版，历史媒体删除需在无商品、任务、资产或画布引用时同步清理存储。

- 详情页复刻一对一流程：创建项目必须选择已有白底四视角主图的商品，并上传 1–18 张参考详情页图片；第 19 张、非图片、超过 20MB 或宽高比超过 3:1 的文件应显示明确中文提示。创建后左侧只展示一张锁定的商品主图和最新商品资料，右侧按顺序展示“参考图 / 生成图 / 修改图”三列配对，数量始终一致。
- 商品资料与提示词：每张任务都应带入品牌、产品类别、材质和全部卖点，但不传入商品名称；参考图只迁移构图、文字排版、色彩、光线、背景和装饰风格，不复制竞品商品、品牌、Logo、价格、原文案或水印。参考图有人物时应保留姿态、动作、肢体表现和画面构图；如果只出现人物部分肢体，应保留可见肢体，不补全未出现的身体部分；同时替换为气质相近且身份不同的新面孔，不复刻或还原原人物。商品自身品牌应保留，商品资料更新后重新生成应使用最新值。
- 生成渠道：管理员渠道一次提交全部待生成配对，每个配对对应一个可刷新恢复的异步任务；个人渠道只在浏览器直连模型，结果上传后写回对应配对，刷新页面后未完成项显示“已中断”，已完成结果保留。单张失败、取消排队、重试不应影响其他配对；并发提交不能突破任务上限，Worker 恢复超时后迟到的上游结果不应留下未关联媒体。
- 提示词与操作：可编辑单张完整提示词、保存或恢复默认模板；服务端替换商品变量并追加不可删除的商品资料和安全规则。查看权限只能预览和下载，不能创建、改标题、编辑提示词、生成、取消或删除；revision 冲突应提示刷新，不静默覆盖。
- 结果与下载：生成结果应保持对应参考图比例，缩略图和原图均可预览，单张下载和按参考顺序拼接长图正常；18 张长图在浏览器 Canvas 高度或像素限制下应自动缩放。删除项目不删除媒体文件和画布静态节点，画布中的关联项目显示为失效。
- 画布集成：商品节点、每张参考图节点和对应结果节点刷新后仍保持 `productId`、项目 ID 和配对 ID 关联；普通图片右键进入复刻时仍需选择商品，已有商品节点可直接预选或打开项目。
- 并发与选择：同一项目多页面同时生成或编辑提示词时应提示 revision 冲突，不应重复创建配对任务；商品选择器可搜索超过首屏数量的已完成商品，画布同步不能把参考图或生成图改写为商品锚点。
- 数据库与服务：详情页配对表和 `product_media_id` 字段完成同步后，已有详情页项目与 MediaFile/MinIO 对象应保留；Prisma Client 或 `detail_page_projects`、`detail_page_pairs` 未初始化时应返回明确中文提示，不再出现 `undefined.count` 或 `undefined.create`。
- 其他已完成能力仍需回归验证：公开注册、管理员模型刷新、Worker 并发与代理、商品图品牌/产品/卖点/材质字段、画布文本放大编辑及全局配置弹窗。
- 管理员渠道模型删除：编辑管理员渠道时可逐个删除模型，保存后模型不再出现在渠道和网站模型选择器中；删除全部模型后渠道仍可保存，并可重新添加模型。
