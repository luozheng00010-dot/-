# 功能介绍

Infinite Canvas 是一个支持多成员账号、云端持久化和服务端 AI 代理的无限画布创作工具。业务数据以 PostgreSQL 为准，图片、视频和音频保存在私有 MinIO Bucket；同一账号在不同浏览器登录后可以访问同一份数据。

## 账号与登录

- 使用账号名和密码登录，Session 保存在数据库中并通过 HttpOnly Cookie 传递。
- 账号名允许 1–10 个中文汉字或英文字母，可混合使用；不允许数字、空格和符号，英文字母大小写不区分。
- 普通密码长度为 8–72 位，服务端使用 Argon2id 保存密码摘要。
- 首次启动自动创建唯一管理员 `root/root`，首次登录必须修改密码。
- 管理员可以创建、软删除、恢复成员和重置密码；删除成员时会立即撤销该成员的全部登录 Session，历史数据仍然保留。

## 成员范围与权限

“我的画布”“生图工作台”“视频创作台”和“我的资产”顶部使用统一的成员范围选择器：

- 本人始终拥有自己数据的编辑权限。
- 管理员始终可以查看和编辑所有未删除成员的数据。
- 管理员可为普通成员授予对其他成员的“查看”或“编辑”权限，一条授权同时覆盖画布、生成记录和资产。
- “查看”权限允许列表、打开、预览、下载和导出，但不允许修改、删除、导入、生成或执行 Canvas Agent 写操作。
- “编辑”权限允许在目标成员名下创建、修改和删除内容。
- 选择具体成员时，新内容归该成员；选择“全部”时，新内容归当前登录用户。
- 列表中的项目、生成记录和资产会显示归属账号。所有权限均由服务端再次校验，不能只靠前端按钮状态绕过。

## 画布项目与云端同步

- 支持创建多个画布项目，以及重命名、删除、批量选择、JSON 导入和导出。
- 画布节点、连线、视口、背景和助手会话以 JSONB 保存到 PostgreSQL。
- 修改画布时自动保存到服务端，每次保存携带 `revision`。如果另一浏览器已写入新版本，服务端返回 `409`，前端停止静默覆盖并提示重新加载或另存副本。
- 不提供多人实时协同编辑；多个浏览器可以读取同一数据，但应通过版本冲突提示处理同时修改。
- IndexedDB 只保留界面偏好、本地缓存和旧版本数据迁移，不再作为画布、生成记录和资产的权威数据源。

## 无限画布

- 支持拖动画布、滚轮缩放、缩放滑杆、重置视图和小地图定位。
- 支持点阵、网格线、空白三种背景，以及浅色和深色主题。
- 支持框选、多选、全选、复制粘贴、删除、节点连线和上下游高亮。
- 支持撤销和重做节点、连线、视口、背景和助手会话变化。
- 支持图片节点、文本节点和生成配置节点，以及通过插件扩展的其他节点类型。
- 图片节点支持上传、替换、下载、裁剪、本地多角度变换和保存到“我的资产”。
- 生成配置节点可以汇总上游文本与图片，统一配置模型、比例和数量，批量生成图片或文本。
- 批量图片结果可作为图片组节点展示，支持叠卡预览、展开查看和设置主图。

## 生图与视频工作台

- 生图工作台保存图片生成、编辑、状态和失败记录。
- 视频创作台保存视频生成任务、轮询状态和结果记录。
- 创建记录时由服务端根据当前成员范围写入真实 `ownerId`，并同时记录实际操作账号，客户端不能伪造归属。
- 工作台历史在同一账号的不同浏览器间同步；“全部”范围可聚合当前账号有权访问的所有成员记录。

## 资产与媒体

- 资产元数据保存在 PostgreSQL，媒体二进制保存在私有 MinIO Bucket。
- 前端业务数据使用 `mediaId` 引用媒体，不再依赖浏览器本地 `storageKey`。
- 上传、预览和下载都经过同源 `/api` 鉴权，不暴露可绕过成员权限的永久裸对象地址。
- 图片、视频和音频可在画布、工作台和“我的资产”之间复用。

## 管理员控制台

管理员控制台提供：

- 创建账号、软删除、恢复和重置密码。
- 为某成员配置其对其他成员的“无权限 / 查看 / 编辑”权限。
- 新建、编辑、启用或停用模型渠道。
- 配置渠道协议、Base URL、API Key 和模型能力。
- 查看经过掩码处理的渠道密钥；普通用户不会收到 Base URL 或 API Key。

系统只允许唯一管理员 `root`，不能创建第二个管理员，也不能删除、停用或改名 `root`。

## AI 生成与服务端代理

所有图片、编辑、文本、音频、视频和画布助手请求都通过 `/api/ai` 服务端代理。管理员集中配置渠道，普通用户只读取已启用的渠道名称、模型名称和能力。

首版支持三类标准协议：

- OpenAI 兼容协议。
- Gemini 标准协议。
- 火山方舟标准协议。

渠道 API Key 使用服务端环境密钥进行 AES-256-GCM 加密保存。被停用的渠道或模型不能调用；前端不再提供任意 JavaScript 调用脚本，也不允许普通用户自行保存渠道密钥。

## Canvas Agent 与插件

- 画布助手可以围绕选中节点和上游节点进行对话、生图，并把结果插回画布。
- 本地 Canvas Agent 可以连接 Codex / Claude Code，并通过 MCP 操作当前画布。
- 查看他人只读画布时，Canvas Agent 的写操作会在前端禁用，并由后端权限校验再次拒绝。
- 节点插件系统仍支持安装、启用、更新和卸载远程插件，并提供 TypeScript SDK。

## 旧数据迁移与导入导出

- 登录后会检测旧 IndexedDB 中的画布、资产、生图记录、视频记录和媒体文件，并展示数量和空间占用。
- 用户确认后，系统先上传媒体并建立 `storageKey → mediaId` 映射，再迁移业务数据。
- 迁移使用“账号 + 数据类型 + 原本地 ID”作为幂等键，失败后可以安全重试，重复执行不会生成副本。
- 成功后仅写入本地完成标记；旧 IndexedDB 数据保留，但不再参与业务读取。
- JSON 导入到具体成员范围时归该成员，处于“全部”范围时归当前登录用户；文件中的所有者字段会被服务端忽略。
- WebDAV 不再是主同步方式，仍可通过 JSON 导入和导出进行人工备份或迁移。

## 部署架构

Docker Compose 包含四类服务：

- Nginx/Web：提供前端静态文件，并将 `/api` 同源转发到 API。
- API：Express + Prisma，负责认证、权限、持久化和 AI 代理。
- PostgreSQL：保存账号、Session、权限、画布、生成记录、资产和渠道配置。
- MinIO：保存私有图片、视频和音频对象。

生产环境必须设置独立的 PostgreSQL 密码、MinIO 凭据、`SESSION_SECRET` 和 `CHANNEL_ENCRYPTION_KEY`，并持久化 PostgreSQL 与 MinIO 数据卷。更换渠道加密密钥后，已有 API Key 将无法解密。

## 当前限制

- 暂不支持多人实时协同或自动合并冲突。
- 同时编辑依赖 `revision` 检测，发生冲突后需要重新加载或另存副本。
- 旧 WebDAV 和本地存储实现仅用于兼容迁移，不再作为业务主数据源。
