# 本地短素材语义剪辑：集成与验收

本次代码待人工验收，未运行构建、测试、数据库迁移或样例生成。在线素材仍使用原流程；主站本地模式已关闭旧随机／顺序任务入口。

## 使用流程

1. 管理员在「自动剪辑 → 管理设置」选择文案／匹配、视觉分析、向量三个主站渠道模型，保存并测试视觉能力。渠道采用 OpenAI 兼容协议；视觉模型必须支持图片输入，向量模型必须支持 `/v1/embeddings`。向量模型目前登记在主站文字模型列表中。
2. 「本地素材库」上传时指定货号、分类。中文原名用于展示，实际文件使用 UUID 键。上传后自动排队探测与分析；已有记录默认待分析，选择后批量启动。分析失败可重试，不重新上传。每批最多 100 条，列表可分批操作。
3. 检查简介、部位、动作、景别、场景、颜色、画质提示与通用镜头标记。超过／达到 5 秒的素材要求人工检查。低清片不会在合成时被静默丢弃。AI 重分析人工标注时只保存建议；编辑框确认后才覆盖并索引。即使视觉调用失败，已探测出的媒体信息仍保留，可人工标注并索引。
4. 工作台选择本地来源、一个货号和多个分类，粘贴最终原文，选择系统音色、数量 1–5，点击「分析文案并匹配画面」。本地模式不自动改写或补全文案。
5. 在「本地剪辑方案」查看每句原文、真实配音时间、候选、选中镜头、使用区间、理由、缺口与重复。浏览器轻量预览按同一音频时钟切换镜头；遇到缺口暂停。此预览用于检查内容和节奏，最终字幕样式与 BGM 在渲染时合成。
6. 缺口可通过新增素材后重匹配本句、手动添加候选、调整顺序与裁剪、明确允许相关素材重复、主动选择 0.8–1.0× 慢放来处理。勾选本句确认代表已检查不确定匹配及缺失证据。关闭字幕仍保留配音对齐。每条成片分别确认后提交。
7. 修改原文、音色、语速或筛选范围会使旧确认失效；「修改本句文案」只重做本句配音与匹配，其他句子的实际音频样本及镜头复用，整篇编辑则重建方案；仅改输出样式会复用配音及镜头。已提交的渲染保存独立快照，不受后续素材标注、归类或逻辑删除影响。

## 部署

- 数据库使用现有 PostgreSQL + pgvector。迁移文件：`server/prisma/migrations/20260917020000_semantic_local_video/migration.sql`，在素材库及模型设置迁移之后应用。为不定维度 `vector` 保存模型标识、维度、标注版本；不创建 HNSW 索引。
- 由部署人员执行 `npm --prefix server run prisma:migrate`、`npm --prefix server run prisma:generate`，再按既有流程部署主服务和 worker。开发启动继续采用既有 `dev:prepare`（generate + db push）约定，根目录 `npm run dev` 先准备数据库，再启动 API、worker、Web、引擎。不要在同一数据库同时运行 migrate 与 db push。
- Python 增加直接依赖 filelock，版本沿用现有 uv.lock 中的 3.25.2；安装依赖后重启引擎。没有自动运行 uv sync／lock。
- API 和 worker 都需设置 `AUTO_VIDEO_API_URL`。本地默认 `http://127.0.0.1:8080`，Compose 已使用 `http://auto-video:8080`。如启用引擎认证，将两者的 `AUTO_VIDEO_API_KEY` 设置为引擎 `config.toml` 中 `app.api_key` 的相同值。浏览器不会拿到该值或渠道密钥。
- 持久保存数据库、`auto-video/storage/local_videos` 和 `auto-video/storage/semantic`。后者保存配音、分段缓存、请求签名、合成产物和完成标记。任务由主服务 worker 处理，单独启动 API 或引擎不会消费匹配队列。
- 管理员更换向量模型后点击「重建已标注素材索引」。页面显示当前配置下的有效索引数量，旧模型向量不会进入新检索。通道地址／配置版本变化也会改变索引标识。

## 数据、接口与恢复

`local_video_materials` 保存媒体信息、AI／人工标注、建议标注、版本、向量、分析状态；`auto_video_plans` 保存原文、筛选条件、语义单元、配音和多条方案；`auto_video_jobs` 保存租约、重试、阶段检查点以及渲染快照。

| 接口 | 用途 |
| --- | --- |
| `POST /api/local-materials/analyze` | `{ids:[]}` 分析或重试，最多 100 条 |
| `PATCH /api/local-materials/:id/annotation` | `{revision,annotation?,acceptProposed?,disabled?}` 人工确认、采用建议或禁用 |
| `GET /api/local-materials/index-status` | 当前模型索引就绪数量 |
| `GET /api/local-materials` | 媒体、标注及处理状态，支持原有分页筛选 |
| `POST /api/auto-video/admin/settings/test-vision` | 管理员测试四色图识别能力 |
| `POST /api/auto-video/admin/settings/reindex` | 管理员分队列重建已标注素材 |
| `POST /api/auto-video/plans` | `{requestId,script,skuId,categoryIds,voiceName,voiceRate,count,options}` |
| `GET /api/auto-video/plans`、`GET /plans/:id` | 当前用户方案列表、详情与任务状态 |
| `PATCH /plans/:id` | `{revision,edit:{variant,unit,shots,confirmed,allowRepeat}}` 或 `{revision,options}` |
| `POST /plans/:id/rematch` | `{revision,units?}` 重匹配指定句；`{revision,unit,unitText}` 修改本句并复用其余配音；`{revision,input}` 重建整个方案 |
| `POST /plans/:id/render` | `{revision,variant,requestId}` 提交已确认快照 |
| `POST /plans/:id/jobs/:jobId/retry` | 重试失败渲染，保留原快照 |
| `GET /plans/:id/audio`、`GET /plans/:id/jobs/:jobId/video` | 经过用户归属校验的音视频流 |

表中缩写 `/plans/...` 均位于 `/api/auto-video` 下。服务端重算帧数，禁止客户传入实际文件路径。方案创建按用户 + requestId 去重，渲染按方案 + 版本 + variant 去重；失败渲染可原任务重试。旧版本写入返回 409。候选 ID、货号、分类、删除／禁用状态及标注版本在提交时重新验证并锁定，再固定文件键和源区间。

分析／索引全局并发 2，匹配并发 1，渲染并发 1。队列通过 PostgreSQL 行锁、advisory lock、90 秒租约和 15 秒心跳控制多进程并发，过期租约可恢复；结果发布检查租约令牌。连接失败、429、5xx 最多自动重试 2 次。参数、版本与语义校验错误不自动重试。引擎使用文件锁、请求签名和完成标记复用同请求产物；模型分组、配音和候选结果也有检查点。外部供应商若在响应丢失前已计费，重试是否再次计费仍取决于供应商，不承诺外部请求恰好执行一次。

原文按标点初分，模型仅提交连续原句索引；主服务构造并验证 JavaScript UTF-16 字符区间，Python 通过单元文本拼接验证原文，避免 emoji 字符索引差异。整篇配音仅接受实际 cue 事件的严格文本对齐；不能可靠对齐时逐单元配音，以 48 kHz PCM 实际样本拼接，末尾最多补不足一帧的音频静音，画面不定格补时长。

精确余弦检索在物化过滤池内执行，避免不同维度被提前比较。初召回 40 条向量结果 + 至多 20 条标签结果；不足时扩大到至多 120 条。相关等级／证据优先，随后按相关分、画质和画幅适配、跨片重复程度排序。每条内部默认不复用素材；自动片段不少于 15 帧。独立 Python 路径逐片段硬切输出指定帧数，校验完整覆盖原配音，再复用既有字幕／混音函数；不会调用旧 `combine_videos`。

## 人工验收清单

- [ ] 配置三个模型；使用不支持图片的文字模型测试应失败；普通成员无法读写管理配置，浏览器网络中无渠道密钥。
- [ ] 上传真实 1–2 秒无声视频和中文／emoji 名称；探测、5 个位置抽帧、简介、标签、预览、原名显示正确。超过 5 秒及多场景需确认，低清有提示。
- [ ] 停用模型使分析失败；上传结果仍成功，重新配置后可重试。已有素材未点击分析前没有模型调用。人工修改重建向量；重新 AI 分析只出现建议，不覆盖原标注。
- [ ] 使用文案「拉链顺滑，开合方便。内部分区清楚。日常出门好搭。」：拉链句选择开合镜头，分区句选择内里，泛化句允许通用展示并有理由。
- [ ] 仅有外观与面料特写时，「防水」「耐磨」等具体卖点必须出现缺证据／缺口，不自动拿外观作证明；人工选择需明确确认。
- [ ] 单句 4.6 秒可由 1.5 + 1.8 + 1.3 秒覆盖；少素材时显示精确缺少秒数。无隐藏循环、慢放、定格；默认原速，片段最短 0.5 秒，原片不足 0.5 秒仅人工指定。
- [ ] 中文标点、换行、空格、emoji 原文完整且顺序不变；字幕关闭仍能匹配。整篇 cue 失败时检查分段 PCM 对齐，配音生成失败有明确原因。
- [ ] 单句试听、单片预览和轻量合成预览正常；短片切换缓冲时暂停旁白。替换、上移、删除、末镜对齐、主动重复／慢放重新计算时长。
- [ ] 一次生成 1–5 个方案，分别确认。相同候选跨成片复用有提示；片内重复默认禁止。各输出的镜头、区间、速度及旁白与方案一致。
- [ ] 修改文本／配音／筛选后原确认失效；只改画幅、字幕或 BGM 不重新检索。未确认、存在缺口或超出时不能出片。
- [ ] 确认前删除／禁用／修改标注／移出筛选范围的素材阻止提交；提交后的逻辑删除或标注变化不影响固定快照出片。
- [ ] 停止引擎、临时断网、停止 worker 后重启、超时重试均有可解释状态；旧租约不能覆盖新结果；同一确认版本重复点击只有一个渲染任务。
- [ ] 在专用数据库运行千级测试；切换向量模型后旧向量不进入检索，重建中可见未就绪状态。跨用户访问方案、伪造 ID、路径穿越、越界区间和旧版本 PATCH 均拒绝。
- [ ] 输出 30 fps，无黑帧／空洞／累计偏差；字幕、旁白、音乐、横竖画幅正确。BGM 失败显示警告，画面或渲染失败不得回退为随机拼接。
