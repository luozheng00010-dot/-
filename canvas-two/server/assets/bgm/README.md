# BGM 背景音乐库

导出成片时的可选 BGM 曲库（F3b）。导出参数 `bgm` 传曲目 id（即去扩展名的文件名）即可混入，`bgmVolume` 控制音量（0-1，默认 0.15，旁白存在时恒定低音量）。

## 使用方式

- 把**可商用**的 mp3 文件放进本目录即可，系统自动识别并列入导出可选清单：
  - `id` = 去掉 `.mp3` 扩展名后的文件名；
  - `fileName` = 完整文件名（即界面展示的曲名）；
  - **中文命名可用**（如 `轻快日常.mp3` → id 为 `轻快日常`）。
- 扩展名不区分大小写（`.mp3` / `.MP3` 均识别）；其他文件（本 README、txt 等）会被忽略。
- 本目录没有任何 mp3 时，导出接口不提供 BGM 选项（不影响纯旁白 / 无旁白的导出流程）。
